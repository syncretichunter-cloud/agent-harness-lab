# Agent Harness 工程学习笔记：课程正文

课程范围、先修、代码交付与验收标准见 [逐期课程目录](../roadmap.md)。当前尚未发布正文。

## 主线

- **00** 从模型调用到任务完成：Agent Harness 到底负责什么？
- **01** Harness 的最小循环：模型怎样行动、接收反馈并停止？
- **02** Harness 的任务状态：中断后怎样恢复而不重复执行？
- **03** Harness 的工具执行层：从 Function Calling 到 MCP
- **04** Harness 的信息供给：什么时候检索，什么时候查询？
- **05** Harness 的上下文管理：每次调用前该交给模型什么？
- **06** Harness 的长任务执行：拆解、交接与完成证据
- **07** Harness 的控制流：Workflow、规划与多 Agent 怎样选择？
- **08** Harness 的动作边界：权限、安全与人工接管
- **09** 评测 Harness：同一个模型，执行机制怎样影响任务结果？
- **10** Harness 的可观测性：用 Trace 找到根因并验证修复
- **11** Harness 的模型适配：故障、降级与预算怎样控制？
- **12** 交付完整 Agent Harness：从干净环境跑通端到端任务

## 扩展篇

- **X01** Harness 的运行环境：任务排队、限流与过载处理
- **X02** Harness 的模型后端：自托管推理的延迟与吞吐
- **X03** 量化后的模型后端：Harness 的工具与任务契约还成立吗？
- **X04** 优化 Harness：能否根据失败轨迹自动改进执行机制？
